# pcb-hardware-projects

以辅助 PCB 开发的工具和插件为主，收集实用程序、脚本、自动化工具及 EDA 扩展，覆盖设计、检查、制造资料整理和调试等环节。

同时保留少量硬件项目，用于存放 PCB 设计、原理图、Gerber、BOM、固件及项目文档。

## 目录约定

| 目录 | 用途 |
| --- | --- |
| [tools/](tools/) | 主要内容：辅助 PCB 开发的工具、实用程序、脚本和自动化流程 |
| [plugins/](plugins/) | 主要内容：EDA 及相关软件的插件、扩展和集成 |
| [projects/](projects/) | 辅助内容：独立硬件项目的设计、制造、固件及文档资料 |

每个工具、插件或硬件项目使用独立子目录，并附上 README，说明用途、使用方法和当前状态。
