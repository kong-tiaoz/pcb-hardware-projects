# PCB 小工具（整合版）

在最初的 [MIL-mm 单位转换器](../mil-mm-converter/) 基础上，新增走线载流计算功能，并将两部分整合到同一个程序中。

## 功能

- MIL 与 mm 双向即时换算。
- 按持续电流或 RMS 电流、允许温升、成品铜厚估算所需线宽。
- 按已有线宽、允许温升、成品铜厚估算持续载流能力。
- 线宽同时显示 mm 与 MIL，铜厚支持常用预设与自定义。

## 下载与使用

下载 [PCB小工具.exe](./PCB小工具.exe?raw=1)，在 Windows 上双击运行。程序离线使用，无需安装；需要 .NET Framework 4.x。

程序通过选项卡提供“IPC-2152 走线载流”和“MIL / mm 单位转换”两个功能界面。

完整计算模型、适用范围、来源与操作说明见原始 [使用说明.txt](使用说明.txt)。
