PCB 小工具

功能
1. MIL/mm 双向即时换算：1 MIL = 0.0254 mm。
2. 根据持续电流（或 RMS 电流）、允许温升、成品铜厚估算所需线宽。
3. 根据已有线宽、允许温升、成品铜厚估算持续载流能力。
4. 线宽同时显示 mm 与 MIL；铜厚支持常用预设和自定义。

计算模型
采用 Lazar Rozenblat 发布的 IPC-2152 图 5-2 通用曲线拟合，独立编写实现：
A = (117.555 * ΔT^(-0.913) + 1.15) * I^(0.84 * ΔT^(-0.108) + 1.159)
A 为 MIL²，I 为 A，线宽 MIL = A / 铜厚 MIL。
温升范围 2–100℃；正向电流范围 0–30 A（不含 0）。反算超出 30 A 时不显示外推数值。
基准为静止空气、约 1.78 mm 厚聚酰亚胺板的 3 oz 测试曲线。
未进行板材、板厚、铜平面、铜厚热效应、邻近热源等完整修正；内外层共用该基准。
铜厚仅用于将截面积换成线宽。预设 1 oz 约 35 μm，优先输入板厂实际成品铜厚。
结果未加设计裕量，不是 IPC 标准完整实现或认证，实际板需核对温升。
温升是相对周围环境的温差，不是走线的绝对温度。

来源

验证
已核对公开示例：10 A、20℃，截面积 513.0943 MIL²（来源给出 513.1）。
已检查不同铜厚、电流、温升的正反算及数值边界，共 247 项检查通过。

使用
双击 PCB小工具.exe 或桌面快捷方式。离线使用，无需安装。
需要 Windows .NET Framework 4.x（当前电脑已安装 4.8）。
source 文件夹保存源文件，方便以后修改。
