# 更新记录

按实际开发顺序记录两个阶段，并在仓库中通过两次独立提交归档。

## 第一阶段：MIL-mm 单位转换器

- 先完成 MIL（密耳）与 mm（毫米）的双向单位换算。
- 初版程序为 `MIL-mm转换器.exe`，保存在 [mil-mm-converter/](../mil-mm-converter/)。

## 第二阶段：新增走线载流并整合

- 随后开发走线载流计算功能：按电流估算线宽，以及按线宽估算持续载流。
- 将走线载流功能与已有的 MIL-mm 换算功能整合在一个程序中。
- 整合后程序为 `PCB小工具.exe`，通过选项卡切换两类功能。
- 一并保存整合版源码和原始使用说明。

这次归档保留了初版与整合版两个实际程序；两次上传提交均记录本次归档时间。
