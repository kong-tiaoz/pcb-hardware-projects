# 硬件项目

本目录用于存放仓库中的少量硬件项目及配套资料；仓库的主要内容是 `tools/` 和 `plugins/` 中的 PCB 辅助工具与插件。

每个项目使用一个独立目录，建议以简短、清晰的英文名称命名。

## 建议目录结构

```text
<project-name>/
├── README.md       # 项目介绍、板卡版本和使用说明
├── schematic/      # 原理图源文件及 PDF
├── pcb/            # PCB 设计源文件
├── gerber/         # Gerber、钻孔文件及制造说明
├── bom/            # BOM 及采购说明
├── firmware/       # 固件源码及构建说明
└── docs/           # 接口说明、调试记录、图片和测试结果
```

## 文件约定

- 项目 README 记录项目用途、设计工具、板卡版本和当前进度。
- 保留可编辑的原理图和 PCB 源文件。
- Gerber 和 BOM 按板卡版本保存，并注明对应的设计版本。
- 固件说明包含构建方法、烧录方式及适用板卡版本。
- 按项目实际需要创建目录，无需提前建立空目录。
